# Android checklist

Copy this list into a pull request, design review or project kickoff and tick what applies.
Rules are grouped by level and sorted by score ([criteria](../RANKING.md)). Each links to the file that explains it and cites its sources.
*Automatable* names tools that can check the rule in CI (see the file's "How to enforce" section).

Also apply the [general checklist](general.md).

This file is generated by `python3 scripts/rank.py fix` from the guidelines. Don't edit it by hand.

## Strongly recommended (9–10)

- [ ] `ANDROID-1` (9) Use a UI layer and a data layer, and add a domain layer only when logic is complex or reused. ([specific/android](../specific/android/README.md)) *Automatable: Konsist, architecture assertions.*
- [ ] `ANDROID-2` (9) Keep a single source of truth for each data type, and use unidirectional data flow: state flows down, events flow up. ([specific/android](../specific/android/README.md)) *Automatable: Slack compose-lints.*
- [ ] `ANDROID-3` (9) Expose UI state from ViewModels as observable streams, and keep UI elements free of business logic. ([specific/android](../specific/android/README.md)) *Automatable: Konsist, architecture assertions.*

## Recommended (6–8)

- [ ] `ANDROID-4` (8) Access data only through repositories in the data layer. ([specific/android](../specific/android/README.md)) *Automatable: Konsist, architecture assertions.*
- [ ] `ANDROID-5` (8) Use dependency injection (Hilt). ([specific/android](../specific/android/README.md))
- [ ] `ANDROID-6` (7) Follow the coroutine best practices: inject dispatchers, make suspend functions main-safe, and don't expose mutable state. ([specific/android](../specific/android/README.md)) *Automatable: detekt, coroutines rules.*
- [ ] `ANDROID-9` (7) Make every screen usable with TalkBack and Switch Access: describe each meaningful image and icon with a `contentDescription`, pass `null` for decorative ones, expose the role and state of custom components through Compose semantics, and make each touch target at least 48dp by 48dp. ([specific/android](../specific/android/README.md)) *Automatable: Android Lint, ContentDescription, Compose accessibility checks.*
- [ ] `ANDROID-7` (6) Build offline-first where possible, with the local database as the source of truth. ([specific/android](../specific/android/README.md))
- [ ] `ANDROID-10` (6) Set text sizes in `sp`, and test every screen at the largest font size, which is 200% since Android 14, so that text follows the user's setting without being cut off. ([specific/android](../specific/android/README.md)) *Automatable: Android Lint, ContentDescription.*
