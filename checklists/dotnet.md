# .NET / ASP.NET Core checklist

Copy this list into a pull request, design review or project kickoff and tick what applies.
Rules are grouped by level and sorted by score ([criteria](../RANKING.md)). Each links to the file that explains it and cites its sources.
*Automatable* names tools that can check the rule in CI (see the file's "How to enforce" section).

Also apply the [general checklist](general.md).

This file is generated by `python3 scripts/rank.py fix` from the guidelines. Don't edit it by hand.

## Strongly recommended (9–10)

- [ ] `DOTNET-1` (9) Load secrets through configuration providers: user secrets (the Secret Manager) in development, and Azure Key Vault or another vault in production, never `appsettings.json` or source code. ([specific/dotnet](../specific/dotnet/README.md)) *Automatable: GitHub secret scanning push protection.*
- [ ] `DOTNET-2` (9) Go async all the way and never block on async code with `.Result` or `.Wait()`. ([specific/dotnet](../specific/dotnet/README.md)) *Automatable: CA1849, Microsoft.VisualStudio.Threading.Analyzers, VSTHRD002.*
