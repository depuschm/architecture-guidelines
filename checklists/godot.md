# Godot checklist

Copy this list into a pull request, design review or project kickoff and tick what applies.
Rules are grouped by level and sorted by score ([criteria](../RANKING.md)). Each links to the file that explains it and cites its sources.
*Automatable* names tools that can check the rule in CI (see the file's "How to enforce" section).

Also apply the [general checklist](general.md).

This file is generated by `python3 scripts/rank.py fix` from the guidelines. Don't edit it by hand.

## Strongly recommended (9–10)

- [ ] `GODOT-1` (9) Commit the `.import` files next to your assets and the `.uid` files next to your scripts and shaders, and ignore the `.godot/` folder. ([specific/godot](../specific/godot/README.md))

## Recommended (6–8)

- [ ] `GODOT-3` (8) Design scenes to work on their own: keep what a scene needs inside it, and let the parent supply any outside dependency. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-4` (7) Let parents call methods on and set properties of their children, and let children report what happened through signals. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-5` (7) Use autoloads only for broad-scoped systems that manage their own data, such as a quest or dialogue system. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-9` (7) Use static typing throughout, and set the `untyped_declaration` warning to Error so that untyped declarations stop a script from compiling. ([specific/godot](../specific/godot/README.md)) *Automatable: GDScript warning system.*
- [ ] `GODOT-11` (7) Move objects and run game logic in `_physics_process`, and turn on physics interpolation so that motion stays smooth at any frame rate. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-12` (7) Model designer-edited game data as custom Resource classes saved as `.tres` files. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-13` (7) Write saves and settings to `user://`, and don't decode objects (`allow_objects`) from files that players can edit or share. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-14` (7) Write automated tests with GUT or gdUnit4, and run them headless in CI on every change. ([specific/godot](../specific/godot/README.md)) *Automatable: gdUnit4 command line tool, GUT command line.*
- [ ] `GODOT-2` (6) Use snake_case for file and folder names (C# scripts excepted), and keep third-party code in `addons/`. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-6` (6) Reference other nodes through `@export` properties or scene-unique names (`%Name`), not long hard-coded node paths. ([specific/godot](../specific/godot/README.md))
- [ ] `GODOT-10` (6) Follow the GDScript style guide, including its code order. ([specific/godot](../specific/godot/README.md)) *Automatable: gdlint.*
