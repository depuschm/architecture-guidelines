# Reading list

Complete tutorials, guides and books, referenced as a whole. Topic files link to specific chapters where relevant.

## Free online guides and tutorials

- [Software Architecture Guide](https://martinfowler.com/architecture/) (Martin Fowler): a curated set of articles on architecture.
- [Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/): styles, patterns, best practices and reference architectures.
- [AWS Builders' Library](https://aws.amazon.com/builders-library/): articles on how Amazon builds and runs distributed systems.
- [Google SRE books](https://sre.google/books/): *Site Reliability Engineering*, *The Site Reliability Workbook* and *Building Secure and Reliable Systems*.
- [Software Engineering at Google](https://abseil.io/resources/swe-book): engineering practices at scale.
- [The System Design Primer](https://github.com/donnemartin/system-design-primer): a structured self-study course on large-scale system design.
- [The Architecture of Open Source Applications](https://aosabook.org/en/): real systems explained by their authors.
- [Microservice Architecture](https://microservices.io/patterns/index.html) (Chris Richardson): a pattern language with examples.
- [Domain-Driven Design Quickly](https://www.infoq.com/minibooks/domain-driven-design-quickly/): a free introductory e-book.
- [Refactoring.Guru](https://refactoring.guru/design-patterns): an illustrated design patterns tutorial.
- [Game Programming Patterns](https://gameprogrammingpatterns.com/contents.html) (Robert Nystrom): design patterns for games and real-time software, free to read online.
- [Patterns.dev](https://www.patterns.dev/): design, rendering and performance patterns for web apps.
- [Awesome Software Architecture](https://github.com/mehdihadeli/awesome-software-architecture): a large curated link collection.

## Books

- [Fundamentals of Software Architecture](https://fundamentalsofsoftwarearchitecture.com/) (Richards and Ford).
- [Software Architecture: The Hard Parts and other books](https://www.developertoarchitect.com/books.html) (Ford, Richards, Sadalage, Dehghani).
- [Building Evolutionary Architectures](https://evolutionaryarchitecture.com/) (Ford, Parsons, Kua, Sadalage).
- [Domain-Driven Design](https://www.domainlanguage.com/ddd/) (Eric Evans).
- [Designing Data-Intensive Applications](https://dataintensive.net/) (Martin Kleppmann).
- [Building Microservices and Monolith to Microservices](https://samnewman.io/books/) (Sam Newman).
- [Patterns of Enterprise Application Architecture](https://martinfowler.com/books/eaa.html) (Martin Fowler).
- [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/) (Hohpe and Woolf).
- [Team Topologies](https://teamtopologies.com/book) (Skelton and Pais).
- [Release It!, 2nd edition](https://pragprog.com/titles/mnee2/release-it-second-edition/) (Michael Nygard).
- [The Pragmatic Programmer, 20th anniversary edition](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/) (Thomas and Hunt).
- [The Software Architect Elevator](https://architectelevator.com/book/) (Gregor Hohpe).
