# Unreal Engine: rendering and shaders

Shader and PSO compilation, the shared Derived Data Cache, materials and their permutations, Nanite and Lumen, and quality settings for each platform. The engine-independent rendering rules are in [Graphics and GPU rendering](../graphics/README.md). Profiling, memory and asset loading are in [Content and performance](content-and-performance.md), and frame budgets are in [Game development](../gamedev/README.md).

> Entries are sorted by score from 1 to 10 ([criteria](../../RANKING.md)): 9–10 start here or strongly recommended, 6–8 recommended, 1–5 further reading or conditional.

## Key rules

- `8` `UNREAL-17` **Keep PSO precaching on, hold the first loading screen until `FShaderPipelineCache::NumPrecompilesRemaining()` reaches zero, and test first-run smoothness with `-clearPSODriverCache`.** Count the PSOs that precaching missed with `r.PSOPrecache.Validation`, and add a small bundled PSO cache, one per graphics API you ship, only where precaching leaves hitches. This applies `GFX-5`. ([Unreal Engine, PSO Precaching](https://dev.epicgames.com/documentation/en-us/unreal-engine/pso-precaching-for-unreal-engine), [Creating a Bundled PSO Cache](https://dev.epicgames.com/documentation/en-us/unreal-engine/manually-creating-bundled-pso-caches-in-unreal-engine))
- `8` `UNREAL-18` **Give the team a shared Derived Data Cache, so that each shader and other derived asset is built once for everyone: a Zen Storage Server or a network drive for people in one office, and Unreal Cloud DDC for a distributed team.** Epic strongly recommends a shared DDC for teams in a common location, and it helps most in projects with many Nanite meshes. ([Unreal Engine, Using Derived Data Cache: Shared DDC](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-derived-data-cache-in-unreal-engine#sharedddc), [Zen Storage Server](https://dev.epicgames.com/documentation/en-us/unreal-engine/zen-storage-server-for-unreal-engine), [How to Set Up Unreal Cloud DDC](https://dev.epicgames.com/documentation/en-us/unreal-engine/how-to-set-up-a-cloud-type-derived-data-cache-for-unreal-engine), [Nanite](https://dev.epicgames.com/documentation/en-us/unreal-engine/nanite-virtualized-geometry-in-unreal-engine))
- `7` `UNREAL-19` **Build materials as a few parameterized parent materials, create the variations as Material Instances, and use Material Instance Dynamic only for values that change at run time.** A Material Instance changes a material's look without recompiling its shaders. This applies `GFX-6`. ([Unreal Engine, Material Instances](https://dev.epicgames.com/documentation/en-us/unreal-engine/instanced-materials-in-unreal-engine))
- `7` `UNREAL-20` **Keep material permutations down: use few static switch parameters and few combinations of them across instances, and keep usage flags to the kinds of mesh a material is really used on, because each combination and each flag compiles more shaders.** Use the Material Analyzer to find instances that share the same static overrides and reparent them, and check each platform's shader cost in the Material Editor's Platform Stats. This applies `GFX-6`. ([Unreal Engine, Material Instances: static parameters](https://dev.epicgames.com/documentation/en-us/unreal-engine/instanced-materials-in-unreal-engine), [Material Properties: usage flags](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-material-properties), [Material Analyzer](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-material-analyzer-tool), [Material Editor UI](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-material-editor-ui))
- `7` `UNREAL-21` **Decide for each target platform, before content production starts, whether to use Nanite and Lumen.** Both need a Shader Model 6 GPU on PC (DirectX 12, or Vulkan for Nanite) and are designed for current consoles, and Nanite doesn't support forward rendering, VR stereo rendering or MSAA. Where Nanite is supported, Epic recommends enabling it wherever possible. This applies `GFX-1`. ([Unreal Engine, Nanite Virtualized Geometry](https://dev.epicgames.com/documentation/en-us/unreal-engine/nanite-virtualized-geometry-in-unreal-engine), [Lumen Global Illumination and Reflections](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-global-illumination-and-reflections-in-unreal-engine), [Hardware and Software Specifications](https://dev.epicgames.com/documentation/en-us/unreal-engine/hardware-and-software-specifications-for-unreal-engine))
- `7` `UNREAL-22` **Set rendering quality for each platform and device in `Config/DefaultDeviceProfiles.ini`, through the scalability groups (`sg.*`) and console variables, and test every quality level on low-, mid- and high-spec hardware.** Device profiles are Epic's recommended way to handle scalability across mobile devices and across PC quality levels. This applies `GFX-2`. ([Unreal Engine, Setting Up Device Profiles](https://dev.epicgames.com/documentation/en-us/unreal-engine/setting-up-device-profiles-in-unreal-engine), [Scalability Reference](https://dev.epicgames.com/documentation/en-us/unreal-engine/scalability-reference-for-unreal-engine), [Scalability and the Developer](https://dev.epicgames.com/documentation/en-us/unreal-engine/scalability-and-the-developer-for-unreal-engine))

## How to enforce

Tools that check the key rules above automatically, in CI, the IDE or a commit hook. "Partly" means the tool covers only some of what the rule asks.

- `7` [PSO precache validation](https://dev.epicgames.com/documentation/en-us/unreal-engine/pso-precaching-for-unreal-engine#validation-and-tracking): with `r.PSOPrecache.Validation=2`, a build logs every PSO that was needed but not precached, or precached too late, and `stat PSOPrecache` shows the counts, so an automated playthrough on test hardware can fail on misses. Partly checks `UNREAL-17`.
